PCC CS-502 · B.Tech CSE, Semester 5

Operating Systems

What an operating system does and how it does it — from the system-call boundary through scheduling, synchronization, and deadlock to virtual memory, disk scheduling, and the file system.

39 lectures · 4 units 3 credits 3-0-0 L-T-P 3 / 39 lectures published

Lectures 1–3 are published in full (slides, notes, assignment, and GATE practice set). The remaining 36 lectures ship one at a time.

Open materials. Every lecture ships four freely reusable PDFs: the slide deck, the prose lecture notes, the graded assignment, and a GATE practice set with answers. Solution keys to assignments are never published. A video explainer is linked per lecture.

§ 00 · Before you begin

Prerequisites

Programming in C (functions, pointers, arrays, structs, basic system calls); a working model of the machine a program runs on (CPU, registers, memory, I/O) — CS401 Computer Organization & Architecture or equivalent. Algorithms literacy (asymptotic cost, queues, lists) is assumed for the scheduling and page-replacement analysis.

§ 04 · Hand in your work

Submit an assignment

Assignments are submitted through the course submission form. Type the assignment name exactly as shown in the table above (for example 01-intro-os-structure), attach your file, and submit — you will need to be signed in to a Google account, and your submission is timestamped automatically.

Before you submit: name your file <roll>_CS502_W<NN>.pdf (for example 21BCS045_CS502_W01.pdf) so it is identifiable. Written work should be a single PDF.

There is no automatic late penalty — if you need more time, ask before the deadline and an extension will be granted. Any AI assistance must be cited, per the course AI-use policy.
